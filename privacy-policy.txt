1. INTRODUCTION

This Privacy Policy applies to the Application ("the Application", "we",

functionality for Discord communities.

The Application is developed independently and is not affiliated with,
endorsed by, sponsored by, or operated by Discord Inc.

This Privacy Policy explains what information the Application may access,

The Application may be open source and its source code may be made
available through a public repository maintained by its developer.

By using the Application, you acknowledge that the Application operates
within Discord and that Discord independently processes information in
accordance with its own policies and terms.

2. INFORMATION THE APPLICATION MAY ACCESS

Depending on the features used and the configuration of a Discord server,
the Application may receive limited information from Discord, including:

- Discord user ID;
- Discord server (guild) ID;
- Discord channel ID;
- Discord message ID;
- username or display name made available by Discord;
- information about roles and permissions required to determine whether a
  user may perform an operation;
- information contained in interactions with the Application;
- message content when required to receive and process a command;
- information voluntarily provided by users through the Application's
  features, such as participation information, comments, preferences,
  settings, or other user-submitted content.

The Application does not request or store Discord passwords,
authentication credentials, or users' Discord account tokens.

3. MESSAGE CONTENT

The Application may use the Discord Message Content privileged intent
solely to receive and process commands sent by users.

Message content is processed only to the extent necessary to identify and
execute the relevant command.

Message content is not collected for advertising, profiling, targeted
marketing, sale of information, or any unrelated purpose.

The Application does not intentionally maintain a permanent database of
users' message history solely because it has access to Message Content.

4. PURPOSE OF PROCESSING

Information accessed by the Application is used only as necessary to
operate its features, including:

- receiving and processing user commands;
- creating, modifying, storing, and managing application-related data;
- displaying information relevant to the Application's functionality;
- checking the permissions required to perform an operation;
- temporarily caching information to improve performance;
- reducing unnecessary requests to Discord;
- maintaining, troubleshooting, and securing the Application.

The Application does not use user information for advertising,
behavioral profiling, selling personal information, or building
advertising profiles.

5. STORAGE AND CACHING

Information received from Discord may temporarily exist in the
Application's operational memory and temporary caches.

Caching is used solely to improve Application performance and reduce
repeated requests to Discord.

Temporary data is not intended to constitute permanent storage of Discord
message content.

When the Application process terminates, information held in its
operational memory is released as part of the normal operation of the
hosting environment.

Temporary cached information is removed as part of normal cache cleanup
and Application operation.

The Application does not guarantee that data can never remain temporarily
in operating-system, hosting, backup, logging, or other technical
infrastructure outside the Application's direct control.

6. SHARING AND DISCLOSURE

The Application does not sell user information.

The Application does not provide message content or user information to
advertising networks, data brokers, or other third parties for
advertising or profiling purposes.

Information accessed by the Application is used solely for operating the
Application and providing its functionality.

The Application may necessarily communicate with Discord through
Discord's API and infrastructure. Information transmitted to or received
from Discord is subject to Discord's own terms and privacy practices.

The Application may also disclose information when disclosure is required
by applicable law or is reasonably necessary to protect the Application,
its developer, users, or the security of the service.

https://discord.com/privacy

The Application is designed to keep operational data only for as long as
reasonably necessary for the functionality for which it is used.

Message content received through Message Content is intended for

Some operational information may remain available for the period

Technical information may be retained temporarily for operational,
security, troubleshooting, diagnostic, or abuse-prevention purposes.

No specific universal retention period is promised for every category of
